Knock for real

One sitting, one win: your API proves itself over HTTP — including the full auth allow/deny matrix.

The real problem. Units prove logic; nothing proves the wiring — wrong mount path, missing parser, guard misordered, ownership unscoped. Those are integration bugs, and hand-knocking forgets half the matrix after every change. Today knocks become code: same statuses, asserted automatically.

// file: routes/tasks.routes.test.mjs
import { test, before, afterEach } from "node:test";
import assert from "node:assert/strict";
import request from "supertest";
import { app } from "../app.mjs";
import { query } from "../db.mjs";

before(async () => { /* migrate test DB + seed users A/B + tasks (see key) */ });
afterEach(async () => { /* truncate tasks/sessions, re-seed minimal */ });

async function loginAs(email) {
  const agent = request.agent(app);
  await agent.post("/auth/login").send({ email, password: "correct-horse-123" }).expect(200);
  return agent;
}
test("matrix: owner's task", async () => {
  const a = await loginAs("a@example.com");
  const created = await a.post("/tasks").send({ projectId: "pA", title: "Hi" }).expect(201);
  await a.get(`/tasks/${created.body.id}`).expect(200);
  const b = await loginAs("b@example.com");
  await b.get(`/tasks/${created.body.id}`).expect(404); // other's → hidden
  await request(app).get(`/tasks/${created.body.id}`).expect(401); // stranger → who?
  await a.post("/tasks").send({ title: 42 }).expect(400); // junk → judged
});

Why it works: .expect(status) asserts inline (failure names expected-vs-got); agent jars persist cookies across knocks (login once per identity); exporting app sans listen keeps tests port-free.

Security proof, runnable: the matrix runs on every change (CI in Module 8). 0034 documents these rooms (OpenAPI) and types them (TS); the suite is the net under all future refactors — including Postgres upgrades and Prisma bumps.

6 · Common mistakes

“Tests hit dev DB.” Forgot the dial — suite wipes real tasks. Fix: test files assert the DB name contains test before truncating (guard clause, non-negotiable).
“Shared seed, order matters.” Test B passes alone, fails after A (leftover rows). Fix: wipe + minimal re-seed per test — isolation over speed, always.
“Only happy paths.” 200s asserted, denials assumed — the matrix's whole value is the 401/404/400 column. Fix: chart 106 per room, no exceptions; a room without denial tests is an untested room.
