Rooms get their files

One sitting, one win: app.mjs shrinks to wiring while routes, logic, and storage each own a home — plus lists that page and sort.

Source + page math (click)

Math: page starts at 1, offset = (page-1)*limit, totalPages = ceil(total/limit). Page 0 and negative limits die in the query schema (0019's coerce+jodge, extended) — arithmetic never sees them.

4 · Live demo: the move (12 min)

New files first — services hold the pipeline, routes hold HTTP:

// file: services/tasks.service.mjs
export function listTasks(tasks, { done, sort = "created", order = "asc", page = 1, limit = 10 }) {
  let list = done === undefined ? [...tasks] : tasks.filter((t) => String(t.done) === done);
  const dir = order === "desc" ? -1 : 1;
  list.sort((a, b) => sort === "title"
    ? a.title.localeCompare(b.title) * dir
    : (a.createdAt - b.createdAt) * dir);
  const total = list.length;
  const data = list.slice((page - 1) * limit, page * limit);
  return { data, total, page, limit };
}
// file: routes/tasks.routes.mjs
import { Router } from "express";
import { taskCreate, taskUpdate, taskQuery, judged } from "../schemas.mjs";
import { listTasks } from "../services/tasks.service.mjs";
import { load, save } from "../db.mjs";
import { nanoid } from "nanoid";

export const tasksRouter = Router();
tasksRouter.get("/", async (req, res) => {
  const q = judged(res, taskQuery.safeParse(req.query));
  if (!q) return;
  res.json(listTasks(await load(), q));
});
// ... POST / :id PUT DELETE as before, with load/save (see answer key)
// file: app.mjs (wiring only now):
import express from "express";
import { tasksRouter } from "./routes/tasks.routes.mjs";
const app = express();
app.use(logger); app.use(express.json());
app.get("/health", (req, res) => res.json({ ok: true }));
app.use("/tasks", tasksRouter); // ← rooms move in under one roof
app.use(unknownRoom); app.use(errorLane);
app.listen(3000, ...);

Extend the query photo (schemas.mjs): sort: z.enum(["title","created"]).optional(), order: z.enum(["asc","desc"]).optional(), page: z.coerce.number().int().positive().optional() — then knock:

node app.mjs
node -e "console.log(JSON.stringify(await (await fetch('http://localhost:3000/tasks?sort=title&order=desc&page=1&limit=2')).json(), null, 1))"
# expected: { data:[...2 tasks, Z→A...], total:N, page:1, limit:2 } — envelope!

Why it works: Router is a mini-app — paths inside are relative (/ means /tasks/ once mounted). Services take plain data in, return plain data out — testable without HTTP (Module 7 will).

5 · How this fits TaskFlow

This is the building's final floor plan: Module 5 swaps db.mjs internals for Postgres (services untouched — the reason-test pays off instantly), Module 6 adds users + auth layers between parser and rooms. The envelope shape is the first thing your future frontend will code against.

6 · Common mistakes

“Routes import the app.” Circular glue — router needs app for no reason. Fix: routers export, app imports. Chart 57 arrows never point up.
“Logic in routes, HTTP in services.” Service returns res.json — untestable without a server. Fix: services return data; only routes touch res.
“Page 0 / limit 1e9.” Arithmetic on unvetted query — empty pages, memory floods. Fix: schema bounds (positive, max 100); math trusts the photo.
