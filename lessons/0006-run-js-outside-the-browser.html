MODULE 2 · NODE FUNDAMENTALS · LESSON 1

JavaScript leaves the browser

One sitting, one win: you run a real program on your machine — with arguments, output, and no browser in sight.

⏱ 25–35 minPrerequisites: Module 1 gateObjectives: runtime split · node run · argv
The real problem. Until today your JavaScript only existed inside a tab: refresh and it's gone, files are unreachable, and “running code” meant “opening a page”. A backend is the opposite — a program that runs on a machine, reads its files, and never needs a tab. Today your laptop becomes that machine.

1 · The mental model: same engine, different vehicle

JavaScript the language never changed. What changed is the runtime around it — the tools parked next to the engine:

① you type the command ② Node loads your file and the words after it (argv) ③ V8 runs it ④ console.log hands text back ⑤ terminal prints it and Node exits. Source + rule (click)

Rule: argv[0] is node itself, argv[1] is your file — yours start at 2. Forgetting this is the #1 beginner off-by-one; chant “zero node, one file, two mine”.

4 · Live demo: greet + the missing DOM (5 min)

Create greet.mjs — same file as Lesson 0001, now with arguments:

// file: greet.mjs
const name = process.argv[2] ?? "future backend dev";
const loud = process.argv.includes("--loud");
let line = `hello ${name} — Node ${process.version}`;
console.log(loud ? line.toUpperCase() : line);
node greet.mjs Ada
# expected: hello Ada — Node v24.x.x
node greet.mjs Ada --loud
# expected: HELLO ADA — NODE V24.X.X

Now prove the vehicle split with one line — run it and read the error like a pro:

node -e "console.log(typeof document)"
# expected: undefined — no DOM in Node, and that's normal, not a bug

Why it works: ?? supplies the default when no name is given; process.argv carries your words in; document is simply not parked in this vehicle (chart 8 said so).

5 · How this fits TaskFlow

CLI TaskFlow v0 (next lessons) is greet.mjs grown up: node tasks.mjs add "Buy milk" instead of node greet.mjs Ada. Same argv pipeline, same exit — plus files (lesson 0007) so tasks survive the terminal closing. The server in Module 3 is the same program that doesn't exit.

6 · Common mistakes

“Double-clicked the file, window flashed.” .mjs files don't run by double-click. Fix: always run from a terminal with node filename.mjs so you see output + errors.
“document is not defined.” You drove browser code into Node's vehicle. Fix: check chart 8 — DOM stays in the browser; in Node use console, process, files.
“argv[0] is my first argument.” Off-by-one: yours start at index 2. Fix: log the whole array once (console.log(process.argv)) and count — zero node, one file, two mine.
