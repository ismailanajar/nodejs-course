The building in a box

One sitting, one win: your API runs identically anywhere — plus shutdowns that finish sentences.

⏱ 30–40 minPrerequisites: Lesson 0036 (ship posture)Objectives: image · compose · graceful
The real problem. “Works on my machine” is a version-skew confession: your Node 24 vs their 20, your .env vs their guesses. Docker packs machine + code + recipe into one sealed box that runs the same everywhere. Plus one manners lesson: killing mid-knock corrupts — shutdowns must finish sentences.

4 · Live demo: box + manners (12 min)

# file: Dockerfile
FROM node:24-alpine
WORKDIR /srv/app
COPY package*.json ./
RUN npm ci --omit=dev
COPY . .
EXPOSE 3000
CMD ["node", "server.mjs"]
# file: compose.yaml (local twin)
services:
  api:
    build: .
    ports: ["3000:3000"]
    environment:
      DATABASE_URL: postgresql://postgres:devpw@db:5432/taskflow
      FRONTEND_URL: http://localhost:5173
    depends_on: [db]
  db:
    image: postgres:17
    environment: { POSTGRES_PASSWORD: devpw }
    volumes: ["pgdata:/var/lib/postgresql/data"]
volumes: { pgdata: {} }
// graceful (server.mjs — the only code change):
const server = app.listen(PORT, ...);
for (const sig of ["SIGTERM", "SIGINT"]) process.on(sig, async () => {
  console.log(`${sig}: draining...`);
  server.close(async () => { await pool.end(); console.log("drained. exit 0"); process.exit(0); });
  setTimeout(() => process.exit(1), 10_000).unref(); // hard stop if stuck
});
docker compose up --build
node -e "console.log(await (await fetch('http://localhost:3000/health')).json())"
# expected: { ok:true } — same building, boxed. Stop with Ctrl+C: watch "draining...".

Why it works: npm ci installs lock-exact (chart 14's receipt, honored); server.close stops intake while finishing flights; pool drains before exit (no severed queries); depends_on orders startup (migrations still run pre-serve).

6 · Common mistakes

“COPY . before npm ci.” Every code edit invalidates the dep cache — 3-minute rebuilds. Fix: chart-120 order (manifest first, code last).
“localhost as DB host in box.” Box-localhost is the box, not your machine — connection refused. Fix: service hostname (db) inside compose networks.
“No graceful handler.” Deploys SIGTERM mid-write — torn rows, confused clients. Fix: drain pattern above in every server you ever ship.
