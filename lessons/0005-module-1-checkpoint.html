1 · Cover-and-draw #1: the full lifecycle

Close this page (seriously). On blank paper, draw every step from fetch call to resolved value, including host/port routing and the .ok check. Then uncover and diff against the reference:

sequenceDiagram participant U as You (code) participant B as Browser / Node fetch participant N as Network (host + port) participant S as Server handler U->>B: fetch(url, options) B->>B: build REQUEST text B->>N: send to host:port N->>S: deliver to the right door S->>S: route path + validate + logic S->>N: RESPONSE text (status + JSON) N->>B: deliver reply B->>U: resolve res — YOU check .ok
