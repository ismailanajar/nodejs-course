MODULE 3 · SERVER FROM SCRATCH · LESSON 1

The program that waits

One sitting, one win: your code answers a knock on door 3000 — from a browser and from the terminal.

⏱ 30–40 minPrerequisites: Module 2 gateObjectives: listen · handler · first reply
The real problem. Every program you've written exits. A server is the opposite shape: it starts, opens a door, and waits — possibly forever — answering each knock with the same function. Today you build that shape in ~15 lines, no framework, no magic.

2 · Anatomy of one knock

sequenceDiagram participant K as knock (browser/fetch) participant D as door :3000 participant H as handler(req, res) K->>D: TCP arrives D->>H: built req { method, url } + empty res H->>H: YOUR code decides H->>K: res.writeHead + res.end(body)

Chart 30 — One knock, four hops. Node builds the objects; you only write the middle hop (decide) and the last call (reply).

Source + what Node gifts you (click)

Gifted: parsing bytes into req.method/req.url, and a res that formats your answer back into bytes. Yours: read the two fields, pick status + body, call res.end. Forget res.end and the client hangs — the commonest first-day bug, with a one-line fix.

4 · Live demo: hello on door 3000 (8 min)

Create hello-server.mjs — built-in node:http only:

// file: hello-server.mjs
import http from "node:http";

const server = http.createServer((req, res) => {
  console.log(`${req.method} ${req.url}`); // every knock, logged left
  res.writeHead(200, { "content-type": "text/plain" });
  res.end("hello from TaskFlow server\n");
});

server.listen(3000, () => {
  console.log("listening on http://localhost:3000 (Ctrl+C to stop)");
});
# LEFT terminal:
node hello-server.mjs
# expected: listening on http://localhost:3000 (Ctrl+C to stop) — prompt NOT back
# RIGHT terminal:
node -e "console.log(await (await fetch('http://localhost:3000/')).text())"
# expected: hello from TaskFlow server — and LEFT prints: GET /
# or open http://localhost:3000 in a browser — same knock, same reply

Now trigger the warned-about crash on purpose — start the server twice (second LEFT terminal or same after forgetting Ctrl+C):

node hello-server.mjs
# expected: Error: listen EADDRINUSE: address already in use :::3000
# translation: the door is taken — kill the first server (Ctrl+C), don't pick a new port

Why it works: createServer registers your handler; listen binds the door; each knock re-runs the same function with fresh objects. The crash is the OS refusing two receptionists at one desk.

6 · Common mistakes

“Nothing happens / page spins.” You forgot res.end(...) — the client waits forever for an ending that never comes. Fix: every path through your handler must end exactly one response.
“It worked, now EADDRINUSE.” Old server still holds the door (you closed the terminal, not the process). Fix: Ctrl+C the old one, or find + kill it — never “just use 3001” (that hides the corpse).
“Edited code, nothing changed.” Node doesn't reload files — the running server is the old bytes. Fix: Ctrl+C + re-run after every edit (auto-reload comes with dev tools later; the manual loop builds the mental model).
