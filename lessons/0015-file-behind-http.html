4 · Live demo: wire + verbs (12 min)

Import db.mjs (lesson 0009's env-dial version) and add the two verbs. Replace the in-memory array usage:

// top of server.mjs: swap `const tasks = [...]` for:
import { load, save } from "./db.mjs";
import { nanoid } from "nanoid";

// GET /tasks branch becomes:
if (req.method === "GET" && pathname === "/tasks") {
  const tasks = await load();
  ...same filter, return send(res, 200, list);
}
// POST branch: replace tasks.push with:
  const tasks = await load();
  const task = { id: nanoid(8), title: body.title.trim(), done: false };
  await save([...tasks, task]);
  return send(res, 201, task);

// NEW branches (before the 404 trapdoor):
const parts = pathname.split("/").filter(Boolean);
if (parts[0] === "tasks" && parts.length === 2) {
  const tasks = await load();
  const task = tasks.find((t) => t.id === parts[1]);
  if (!task) return send(res, 404, { error: "unknown task" });
  if (req.method === "PUT") {
    let body;
    try { body = JSON.parse(await readBody(req)); }
    catch { return send(res, 400, { error: "body must be valid JSON" }); }
    if (body.title !== undefined) {
      if (typeof body.title !== "string" || !body.title.trim())
        return send(res, 400, { error: "title must be a non-empty string" });
      task.title = body.title.trim();
    }
    if (body.done !== undefined) {
      if (typeof body.done !== "boolean")
        return send(res, 400, { error: "done must be a boolean" });
      task.done = body.done;
    }
    await save(tasks);
    return send(res, 200, task);
  }
  if (req.method === "DELETE") {
    await save(tasks.filter((t) => t.id !== task.id));
    res.writeHead(204);
    return res.end();
  }
}
# full lifecycle drill (server restarted, LEFT terminal):
T=$(node -e "const r = await fetch('http://localhost:3000/tasks',{method:'POST',headers:{'content-type':'application/json'},body:JSON.stringify({title:'Persist me'})}); console.log((await r.json()).id)")
node -e "console.log(await (await fetch('http://localhost:3000/tasks')).json())"
node -e "console.log(await (await fetch('http://localhost:3000/tasks/$T',{method:'PUT',headers:{'content-type':'application/json'},body:JSON.stringify({done:true})})).json())"
node -e "console.log(await (await fetch('http://localhost:3000/tasks/$T',{method:'DELETE'})).status)"
# expected: 204 — then restart server, GET /tasks → [] (deleted, and it STAYED deleted)

Why it works: 204 means “done, nothing to say” — no body, so no send (raw writeHead+end). PUT is partial here (only sent keys change) — full-replace vs patch is a design choice your contract should state; ours states partial.

5 · How this fits TaskFlow

HTTP v1 is done: restart-proof CRUD over the network with validated input and honest statuses. Module 4 replays this entire building in Express — same branches, tenth of the hand-rolled code — and you'll feel precisely what the framework earns. The race (chart 39) waits for Postgres to resolve it.

6 · Common mistakes

“Cached array at top of file.” const tasks = await load() once at startup — writes from other processes invisible, restarts required. Fix: load inside every branch (fresh truth per knock).
“204 with a body.” Sent JSON alongside 204 — clients ignore it by spec, confusion follows. Fix: 204 ends empty, always.
“PUT replaces vs patches — picked silently.” Ours patches (partial); a teammate assumes replace. Fix: one contract sentence (“PUT here is partial”) — ambiguity about verbs is a 400-series bug factory.
