Knocks that carry things

One sitting, one win: your server reads JSON bodies, validates them, and creates tasks with 201.

⏱ 30–40 minPrerequisites: Lesson 0013 (guard routing)Objectives: stream · parse-or-400 · POST
The real problem. GET rooms only show things — the building accepts no deliveries. Creation means the knock carries a parcel (a JSON body), and parcels can be empty, corrupt, or nonsense. Today: receive, inspect, accept (201) or refuse (400) — with reasons.

4 · Live demo: the receiving room (10 min)

Add to server.mjs — a collector helper plus the POST branch (place before the 404 trapdoor):

// helper: collect the whole body text
function readBody(req) {
  return new Promise((resolve, reject) => {
    let text = "";
    req.on("data", (chunk) => {
      text += chunk;
      if (text.length > 1_000_000) reject(new Error("too large")); // 1MB sanity cap
    });
    req.on("end", () => resolve(text));
    req.on("error", reject);
  });
}

// branch (inside createServer, before the 404 line):
if (req.method === "POST" && pathname === "/tasks") {
  let body;
  try {
    body = JSON.parse(await readBody(req));
  } catch {
    return send(res, 400, { error: "body must be valid JSON" });
  }
  if (typeof body?.title !== "string" || !body.title.trim()) {
    return send(res, 400, { error: "title is required (non-empty string)" });
  }
  const task = { id: `t${Date.now()}`, title: body.title.trim(), done: false };
  tasks.push(task);
  return send(res, 201, task);
}
# server running in LEFT terminal (restart it first!):
node -e "console.log(await (await fetch('http://localhost:3000/tasks',{method:'POST',headers:{'content-type':'application/json'},body:JSON.stringify({title:'Learn bodies'})})).status)"
# expected: 201 — LEFT logs: POST /tasks
node -e "const r = await fetch('http://localhost:3000/tasks',{method:'POST',headers:{'content-type':'application/json'},body:'{oops'}); console.log(r.status, await r.json())"
# expected: 400 { error: 'body must be valid JSON' }
node -e "const r = await fetch('http://localhost:3000/tasks',{method:'POST',headers:{'content-type':'application/json'},body:'{}'}); console.log(r.status, await r.json())"
# expected: 400 { error: 'title is required (non-empty string)' }

Why it works: the handler is already async-friendly (Node awaits the returned promise before moving on — one breath per knock, chart 21). The 1MB cap stops one giant parcel from eating memory — your first denial-of-service instinct.

6 · Common mistakes

“await readBody hangs forever.” Client sent no body and never ended? With fetch + method POST this rarely happens — but testing with a bare socket can. Fix: always send a body (even '{}') when knocking POST in tests.
“Validates after pushing.” Junk already stored, error after the fact. Fix: chart 36 order is law — parse → validate → push. Nothing touches the array before both gates pass.
“No size cap.” A 2GB body becomes a 2GB string and your server falls over. Fix: the 1MB reject above — crude, effective, and the reason frameworks set body limits by default.
