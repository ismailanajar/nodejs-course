6 · Retrieval exercises (blank page, then check)

  1. Program redraw — chart 24 from memory, 7 boxes + 6 arrows (§1 rubric).
  2. Cycle + triage — chart 25 from memory with all three branches; then verdict + fix for: (a) empty output on first list, (b) no such task after copy-paste, (c) 20-line trace on add.
  3. Live drill — fresh folder: init, type module, db.mjs + tasks.mjs (add/list), one task added, file shown. No peeking at old code — only charts allowed.
  4. Loop narration — explain stare.mjs's silence using chart 27 in two sentences, out loud.

Done means: two sheets + one working mini-project + one spoken narration. When all pass, Module 3 is unlocked — your program stops exiting and starts listening.
