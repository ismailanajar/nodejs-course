5 · Common capstone traps

“Localhost URLs in prod frontend.” Works for you, nobody else. Fix: API base from env, per environment — chart 124's wrapper reads it once.
“Forgot credentials:include.” Login 200s, everything else 401s — the silent-drop's cousin. Fix: wrapper sets it globally; one test asserts a cookie ride.
“Announced before checklist.” Users find the red you skipped. Fix: chart 125 top-to-bottom, screenshots per box, then announce.

6 · Summary + graduation

From fetch to shipped: messages → addresses → contracts → CLI → servers → Express → Postgres → auth → tests → deploy → live. You can independently build, test, secure, document, and deploy a backend API — the mission, accomplished. Keep the triangle (judge/catch/prove) on everything you build next.
