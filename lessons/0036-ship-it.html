From laptop to internet

One sitting, one win: you can name every step between “works here” and “works for everyone” — then do it.

The real problem. Localhost is a private island: your dials, your database, your ports, your forgiveness. The internet is a public building: strangers knock, secrets must differ, the database lives elsewhere, and “restart and see” wakes users. Shipping is a checklist, not courage — today the list.

Source + silent-drop warning (click)

Silent-drop is the nastiest prod bug: login 200s, next knock 401s, no error anywhere — the browser binned the cookie. Diagnose via DevTools Application→Cookies (absent = flags wrong). Localhost is exempt from Secure; prod never is.

same-site → Lax · cross-site → None + Secure + https · exact origins

4 · Live demo: production-ready checklist (12 min)

Apply to TaskFlow — provider-agnostic (Render/Fly/Railway/VPS all honor the same shape):

// 1 — env-driven everything (app.mjs top):
const PORT = Number(process.env.PORT ?? 3000); // hosts ASSIGN ports — never hardcode
// 2 — CORS final:
app.use(cors({ origin: (process.env.FRONTEND_URL ?? "http://localhost:5173").split(","), credentials: true }));
// 3 — trust proxy for rate-limit + secure cookies behind host proxies:
app.set("trust proxy", 1);
// 4 — /health that checks the DB (hosts route traffic by it):
app.get("/health", async (req, res) => {
  try { await query("SELECT 1"); res.json({ ok: true }); }
  catch { res.status(500).json({ ok: false }); }
});
// 5 — migrate on boot (before listen): await migrate(); then listen.
// 6 — start script: "start": "node server.mjs" (hosts run `npm start`)
FRONTEND_URL=http://localhost:5173 NODE_ENV=production PORT=3000 npm start
node -e "console.log(await (await fetch('http://localhost:3000/health')).json())"
# expected: { ok:true } — DB-reaching health, prod posture, local doors

Why it works: PORT dial obeys the host; trust proxy un-blinds IPs (rate limits hit attackers, not the proxy); DB health fails traffic away from broken instances automatically.

6 · Common mistakes

“Hardcoded 3000 in prod.” Host assigns 10000, app listens 3000 → health never passes → killed. Fix: process.env.PORT always, default for dev only.
“Migrations skipped.” Code expects column the DB lacks → 500s everywhere post-deploy. Fix: migrate step before start, in the deploy pipeline — chart 118 order is law.
“Secrets baked in image.” ENV DATABASE_URL=... in Dockerfile — leaked to registries, logs, layers. Fix: secrets enter at run (vault/vars), never at build.
