Borrow code without fear

One sitting, one win: your project has a manifest, a real dependency, and shortcuts — like every backend on earth.

⏱ 30–40 minPrerequisites: Lesson 0007 (TaskFlow v0)Objectives: manifest · install · import/export
The real problem. v0's ids are Date.now() blobs you can't type, and every helper is copy-pasted. The world's already solved both — thousands of tiny reviewed packages exist. The skill isn't “write everything yourself”; it's borrowing exact versions, on purpose, with one file saying what you took.

4 · Live demo: TaskFlow v0 grows up (8 min)

In your project folder (fresh or v0's), run the setup once:

npm init -y
# creates package.json with defaults — then edit two fields:
npm pkg set type=module
npm pkg set scripts.add='node tasks.mjs add' scripts.list='node tasks.mjs list'
npm install nanoid
# expected: added 1 package — check package.json + package-lock.json now exist

Split storage into db.mjs, slim the router, and swap ids to nanoid (short, typable, collision-proof):

// file: db.mjs
import { readFile, writeFile } from "node:fs/promises";
const FILE = new URL("./tasks.json", import.meta.url);
export async function load() {
  try { return JSON.parse(await readFile(FILE, "utf8")); }
  catch { return []; }
}
export async function save(tasks) {
  await writeFile(FILE, JSON.stringify(tasks, null, 2));
}
// file: tasks.mjs (router only — storage moved out)
import { nanoid } from "nanoid";
import { load, save } from "./db.mjs";
const [cmd, ...rest] = process.argv.slice(2);
if (cmd === "add") {
  const title = rest.join(" ").trim();
  if (!title) { console.error('usage: npm run add -- "Buy milk"'); process.exit(1); }
  const tasks = await load();
  const task = { id: nanoid(8), title, done: false };
  await save([...tasks, task]);
  console.log(JSON.stringify(task));
} else if (cmd === "list") {
  for (const t of await load()) console.log(`${t.done ? "[x]" : "[ ]"} ${t.id} ${t.title}`);
} else if (cmd === "done") {
  const t = (await load()).find((t) => t.id === rest[0]);
  if (!t) { console.error("no such task"); process.exit(1); }
  const tasks = await load(); tasks.find((x) => x.id === t.id).done = true;
  await save(tasks); console.log(JSON.stringify({ ...t, done: true }));
} else { console.log('usage: npm run add -- "TITLE" | npm run list'); }
npm run add -- "Buy milk"
npm run list
# expected: [ ] xK9mQ2vZ Buy milk — short id, typable, committable

Why it works: -- passes words through npm to your script (without it npm eats them); top-level await works because type: module; done from lesson 0007's exercise slots straight into the router.

5 · How this fits TaskFlow

This folder shape — manifest + modules + scripts — is the seed of every backend you'll ever build. Module 3 adds a listening server file; Module 4 adds Express + Zod to the pantry. The done ids you paste today preview why databases use short serial keys (Module 5).

6 · Common mistakes

“Cannot use import statement.” Missing "type": "module". Fix: npm pkg set type=module — then import works everywhere in the folder.
“My args vanished under npm.” You ran npm run add "Buy milk" without --. Fix: npm run add -- "Buy milk" — the double dash forwards everything after it.
“Committed node_modules.” Thousands of files, repo explodes. Fix: create .gitignore with node_modules/ + tasks.json (dev data isn't code) — commit manifest + lock only.
