Files die four deaths: concurrency (chart 39), queries (no filter/sort/page engine), sharing (one machine only), integrity (no rules — a task can point at a user that doesn't exist). Databases answer all four; the price is learning to ask in SQL. Source: PostgreSQL tutorial.

4 · Live demo: up + first table (10 min)

Needs Docker (Module 8 explains it properly; today it's just the launcher):

docker run --name taskflow-db -e POSTGRES_PASSWORD=devpw -p 5432:5432 -d postgres:17
# expected: long hex id — the librarian is hired. No Docker? Install Postgres 17
# locally instead (https://www.postgresql.org/download/) — same door, same language.
docker exec -it taskflow-db psql -U postgres -c "CREATE DATABASE taskflow;"
# expected: CREATE DATABASE

Create the connection dial + first table (save as db/001_tasks.sql — migrations start as numbered files):

-- file: db/001_tasks.sql
CREATE TABLE tasks (
  id         TEXT PRIMARY KEY,
  title      TEXT NOT NULL CHECK (char_length(title) > 0),
  done       BOOLEAN NOT NULL DEFAULT false,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
docker exec -it taskflow-db psql -U postgres -d taskflow -f - < db/001_tasks.sql
# Windows PowerShell: Get-Content db/001_tasks.sql | docker exec -i taskflow-db psql -U postgres -d taskflow
docker exec -it taskflow-db psql -U postgres -d taskflow -c "\d tasks"
# expected: the grid described back — 4 columns, types, key, defaults. Librarian confirmed.

Why it works: CHECK and NOT NULL are integrity rules in the building — corrupt data can't be stored even by buggy code. DATABASE_URL=postgresql://postgres:devpw@localhost:5432/taskflow is the address (host/port/name, chart D again).

6 · Common mistakes

“Port 5432 taken.” A local Postgres already squats the door. Fix: stop it, or map another (-p 5433:5432) and note the dial — doors again, chart 31 habits.
“Edited 001 after applying.” Applied migrations are history — editing rewrites it. Fix: new file 002_....sql with ALTER; the chain only moves forward.
“devpw in production.” Demo password in a real URL. Fix: strong secrets via env dials (lesson 0009's rule, higher stakes) — Module 8 enforces.
