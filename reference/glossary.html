TaskFlow Glossary v0 — earn these by using them

Compressed language for the whole course. Every lesson uses exactly these meanings.

Core

TermDefinitionSay instead of
ClientThe program that starts a request — usually your browser or frontend.frontend, app
ServerA long-running program that waits for requests and sends back responses.backend, cloud
PortA numbered door on a machine where one server process listens.socket, endpoint
HTTP requestA structured message: method + path + headers + optional body.call, fetch
HTTP responseThe server's reply: status code + headers + optional body.return, output
APIA documented set of request/response shapes a client may use.server, database
JSONText format for structured data both sides already parse.object, payload
localhostThe name for “this same machine I'm on now.”127.0.0.1 (same thing, use this word)

Course spine

TermDefinition
TaskFlowThe single task-management project that grows every module from CLI to deployed API.
Route → Controller → Service → DBThe request path inside our API: URL matching, HTTP glue, business logic, persistence.
MiddlewareA function that sees a request before/after its handler (parsing, auth, errors).
